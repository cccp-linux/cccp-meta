# CCCP Linux Meta-package

* cccp-standard-meta: Standard set of CCCP Linux packages
* cccp-boot-meta: Kernel and boot packages

Copy the following into your home dir:

```shell
/etc/skel/.bashrc
/etc/skel/.bashrc.d/
/etc/skel/.profile
/etc/skel/.profile.d/
```
